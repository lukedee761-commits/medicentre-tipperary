# Medicentre — Dr Bastiaan van Eynatten (demo site)

Demo website for a prospective SuirViewDigital client. Static HTML/CSS/vanilla JS, no build step.

**Concept:** "Medicine for the whole of you" — built around the practice's real differentiator (unhurried, whole-person care, in patients' own words). Signature element: breathing concentric rings (Body · Mind · History · Home life). Layout: sticky consultation rail keeping phone/addresses always visible; sticky call bar on mobile.

**Tokens:** spruce `#2E5D4B` · ink `#1F2A26` · linen `#EFF2EA` · sage `#9DB8A6` · amber `#B96F24` (mobile CTA only). Type: Young Serif / Alegreya Sans / Spline Sans Mono.
